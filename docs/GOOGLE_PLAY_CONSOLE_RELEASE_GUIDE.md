## 5. Audit Izin Sistem (*Permissions Audit*)

ScanFlow Convert Dokumen v1.3.1 adalah aplikasi **Zero-Network & Zero-Camera** yang mematuhi standar privasi tertinggi Google Play Console:

| Izin di AndroidManifest | Status | Rincian & Justifikasi |
| :--- | :--- | :--- |
| `android.permission.INTERNET` | ❌ **TIDAK ADA** | Aplikasi 100% offline. Tidak ada transmisi jaringan ke server mana pun. |
| `android.permission.CAMERA` | ❌ **TIDAK ADA** | Fitur scanner kamera telah dihapus. Aplikasi murni menggunakan file picker. |
| `android.permission.MANAGE_EXTERNAL_STORAGE` | ❌ **TIDAK ADA** | Mematuhi Google Scoped Storage standar tanpa izin broad storage yang berisiko ditolak. |
| `android.permission.READ_MEDIA_IMAGES` | ✅ **Ada (Android 13+)** | Hanya untuk memilih gambar galeri saat pengguna ingin melakukan konversi Gambar ke PDF. |
| `android.permission.READ_EXTERNAL_STORAGE` | ✅ **Ada (maxSdkVersion=32)** | Hanya untuk membaca file dokumen pada Android versi lama (Android 8 s.d. 12). |
